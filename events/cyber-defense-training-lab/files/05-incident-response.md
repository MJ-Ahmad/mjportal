# Incident Response Plan

## Response phases

1. Detect
2. Triage
3. Contain
4. Preserve evidence
5. Eradicate
6. Recover
7. Review

## Severity example

### SEV-1

- active compromise
- broad data exposure
- production service unavailable
- security boundary failure

### SEV-2

- suspicious but contained activity
- limited account or host impact
- partial service degradation

### SEV-3

- low-risk anomaly
- false positive or weak signal
- no observed harm

## Roles

- Incident lead
- Technical responder
- Evidence custodian
- Communications owner
- Recovery owner
- Training observer

## Immediate stop conditions

- real user data appears
- lab isolation fails
- unauthorized network route appears
- destructive behavior escapes approval
- monitoring becomes unreliable
- backup integrity is uncertain
