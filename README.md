## শুরু করুন

```bash

./khata start             # ডেটা যাচাই করে http://127.0.0.1:8000 এ ড্যাশবোর্ড চালু করুন
```

## কমান্ড (khata)

| কাজ | কমান্ড |
|---|---|
| সার্ভ ও খোলা | `./khata start [PORT]` · `./khata open` |
| অগ্রগতি লেখা | `./khata log "আজকের পড়া" --category learning --mood 4` |
| পূর্ণ এন্ট্রি | `./khata add "Heading" "Description" --body-file notes.md --tag a,b` |
| ফাইল যুক্ত | `./khata add "Heading" "Desc" --add-file ./proof.pdf` |
| শেষ এন্ট্রি | `./khata list --limit 10` |
| অবস্থা ও সারসংক্ষেপ | `./khata status` |
| সময় (ঢাকা + UTC) | `./khata time` |
| শেখার বিষয় | `./khata learn list` · `./khata learn open geojson` |
| শেখার পেজ তৈরি | `./khata learn build` |
| শেয়ার লিংক বদলান | `./khata url https://your-address/nijer-khata` |
| ব্যাকআপ | `./khata backup` |
| সাহায্য | `./khata help` |

```

khata               কমান্ড শেল

data.json           সব এন্ট্রি (নতুনটা আগে)
registry.json       LIFE ও REG ID কাউন্টার
site.json           শেয়ার লিংকের মূল ঠিকানা
learn/              শেখার হাব
  subjects.json     বিষয় ও ধাপের তালিকা (এটি সম্পাদনা করুন)
  build.py          subjects.json থেকে পেজ তৈরি করে
  index.html        শেখার হাব
  <slug>/index.html প্রতিটি বিষয়ের আলাদা পেজ
terminal/           ব্রাউজার টার্মিনাল (help, time, status, open …)
attachments/        --add-file দিয়ে যুক্ত ফাইল
assets/             লোগো, আইকন, OG ছবি (সব branding ফাইল এখানে)
```

## নতুন বিষয় যোগ করা

1. `learn/subjects.json` এর `subjects` তালিকায় একটি ব্লক যোগ করুন (`slug`, `group`, `name`, `summary`, `phases`)।
2. `./khata learn build` চালান। নতুন পেজ `learn/<slug>/` এ তৈরি হবে এবং হাবে দেখা যাবে।
3. শেখার অগ্রগতি লিখতে: `./khata log "..." --category learning --tag <slug>`

গ্রুপ বদলাতে বা নতুন গ্রুপ যোগ করতে `groups` অংশটি সম্পাদনা করুন।

## আসল Bash টার্মিনাল (Ubuntu)

ব্রাউজারের `terminal/` পেজ একটি **ডেমো**। সেখানে শুধু কয়েকটি কমান্ড চলে, আসল bash চলে না। আসল shell পেতে দুটি পথ আছে।

### পথ ১: নিজের কম্পিউটারে (Ubuntu বা WSL)

Windows হলে আগে Ubuntu ইন্সটল করুন (PowerShell, administrator হিসেবে):

```powershell
wsl --install -d Ubuntu
```

তারপর Ubuntu-র ভেতরে প্রজেক্টে যান (Windows ড্রাইভ `/mnt/c/...` হিসেবে থাকে) এবং:

```bash
./khata setup              # git, Python 3 + pip + venv + pipx, Node.js LTS, .NET SDK 8
./khata doctor             # কোন টুল আছে তার তালিকা
./khata shell              # প্রজেক্ট ফোল্ডারে bash শেল
./khata start              # ড্যাশবোর্ড চালু করুন
```

`khata setup` বারবার চালালেও সমস্যা নেই। .NET অন্য ভার্সনে চাইলে: `DOTNET_CHANNEL=9.0 ./khata setup --no-node`।

### পথ ২: Docker দিয়ে ব্রাউজারে Ubuntu bash

এটি একটি আলাদা Ubuntu 24.04 কন্টেইনার বানায় এবং ttyd দিয়ে ব্রাউজারে bash দেখায়। আপনার computer-এই শুধু চলে।

```bash
cd setup
cp .env.example .env       # TTYD_PASS-এ লম্বা পাসওয়ার্ড দিন
docker compose up -d --build
```

- ব্রাউজারে খুলুন: `http://127.0.0.1:7681` (TTYD_USER / TTYD_PASS দিয়ে লগইন)
- কন্টেইনারের ভেতরে `./khata setup` দিলে সব টুল ইন্সটল হবে।
- ড্যাশবোর্ড: কন্টেইনারে `./khata start`, তারপর `http://127.0.0.1:8000`।
- প্রজেক্ট ফোল্ডার কন্টেইনারের `/root/nijer-khata`-এ mount করা, তাই `data.json` ও `attachments/` আপনার কম্পিউটারেই থাকে।

**নিরাপত্তা:** এই শেল পুরো কন্টেইনারের নিয়ন্ত্রণ দেয়। পোর্ট শুধু `127.0.0.1`-এ খোলা থাকে। এটি কখনো public ইন্টারনেটে বা GitHub Pages-এর লিংকে দেবেন না। দূর থেকে ব্যবহার করতে হলে SSH tunnel ব্যবহার করুন (`ssh -L 7681:127.0.0.1:7681 user@server`)। `setup/.env` কখনো git-এ commit করবেন না।

GitHub Pages স্ট্যাটিক সাইট, তাই সেখানে আসল shell চালানো যায় না। ওয়েবসাইটে শুধু ডেমো টার্মিনাল থাকবে।

## নিচের বার ও মেনু (সম্পূর্ণ ম্যানুয়াল)

প্রতিটি পেজের নিচে পাঁচটি আইকন: **মূল সাইট · ড্যাশবোর্ড · শেখার হাব · টার্মিনাল · মেনু**। মেনু আইকনে চাপলে মেনু, সাব মেনু ও সাব-সাব মেনুর শুধু তালিকা উঠে আসে (কোনো বিস্তারিত লেখা নয়)।

মেনুতে কিছু যোগ বা বাদ দেওয়ার সাথে টার্মিনাল বা কোনো কমান্ডের সম্পর্ক নেই। শুধু `menu.json` ফাইলটি হাতে সম্পাদনা করুন:

```json
{ "menu": [
  { "title": "projects", "children": [
      { "title": "My App", "href": "projects/my-app/" },
      { "title": { "en": "Group", "bn": "গ্রুপ", "ar": "مجموعة" }, "children": [
          { "title": "Deep page", "href": "projects/group/deep.html" } ] } ] }
] }
```

- `children` থাকলে সেটি খোলা-বন্ধ হওয়া ফোল্ডার; `href` থাকলে সেটি লিংক। যত স্তর খুশি নেওয়া যায়।
- `title` সাধারণ লেখা, অথবা `{en, bn, ar}` দিলে ভাষা অনুযায়ী বদলায়।
- `href` প্রজেক্টের মূল ফোল্ডার থেকে লেখা হয় (যেমন `tools/calc.html`); পুরো `https://...` ঠিকানাও চলে।
- বাদ দিতে সেই লাইনটি মুছুন (বা পেজ রেখে তালিকা থেকে সরান)। নতুন পেজে নিচের বার চাইলে পেজের শেষে `<script src="../assets/menu.js" defer></script>` দিন (`../` ফোল্ডারের গভীরতা অনুযায়ী)।

## ব্যক্তিগত ভল্ট (ফটো, ভিডিও, অডিও, ডকুমেন্ট)

হোম পাতার **ব্যক্তিগত** বোতামে গেলে পাসওয়ার্ড চাওয়া হয়। ভেতরের সব ফাইল এনক্রিপ্টেড থাকে; পাসওয়ার্ড ছাড়া কিছু দেখা যায় না।

**কীভাবে ফাইল যোগ করবেন**

1. কম্পিউটারে প্রজেক্ট ফোল্ডারের `private-inbox/` এ zip ফাইল রাখুন (যেকোনো নাম: `photos.zip`, `videos.zip`, `audio.zip`, `documents.zip`)। zip এর ভেতরে ফোল্ডার থাকলেও চলবে।
2. টার্মিনালে চালান:

```bash
pip install cryptography          # প্রথমবার একবার
python3 private_vault.py          # পাসওয়ার্ড চাইবে, তারপর সব এনক্রিপ্ট করবে
python3 private_vault.py status   # কী আছে তার হিসাব দেখুন
```

3. ফাইল চিনে ঠিক জায়গায় রাখা হয়: ছবি → ফটো, mp4/mov → ভিডিও, mp3/m4a → অডিও, pdf/docx/xlsx/txt → ডকুমেন্ট। চেনা না গেলে তালিকায় দেখানো হয়।
4. সব ঠিক থাকলে `private-inbox/` এর zip গুলো মুছে ফেলুন।

**যা মনে রাখবেন**

- পাসওয়ার্ড কোথাও লেখা থাকে না। ভুলে গেলে ভল্ট খোলা যাবে না।
- এনক্রিপ্টেড ফাইল GitHub-এ আপলোড হতে পারে; কিন্তু সাধারণ ফাইল (zip, ডিক্রিপ্ট করা কপি) কখনো আপলোড হবে না — `.gitignore` এ এগুলো বাদ দেওয়া আছে।
- পাসওয়ার্ড যত লম্বা, ততই নিরাপদ। ৮ সংখ্যার পাসওয়ার্ড সহজে অনুমান হতে পারে, তাই বড় বাক্যাংশ বা অনেক অক্ষরের পাসওয়ার্ড ব্যবহার করুন।
- ৫ মিনিট ব্রাউজার ব্যাকগ্রাউন্ডে থাকলে ভল্ট নিজে থেকে লক হয়ে যায়।
- `robots.txt` সার্চ ইঞ্জিনকে `/private/` না ঘাঁটতে বলে, কিন্তু নিরাপত্তার জন্য আসল ভরসা এনক্রিপশন।
- পাসওয়ার্ড বদলাতে: নতুন ভল্ট বানাতে `private/vault/` এর ভেতরের সব ফাইল মুছে আবার চালান।

## Android-এ অ্যাপ হিসেবে ইন্সটল

এই সাইট একটি Progressive Web App (PWA)। ফোনে একবার খুলুন, তারপর:

1. **Chrome** দিয়ে `https://mj-ahmad.github.io/mjportal/` খুলুন।
2. স্ক্রিনের নিচে "📲 অ্যাপ হিসেবে ইন্সটল" বোতামে চাপুন। বোতাম না এলে Chrome মেনু (⋮) → **Install app** / **Add to Home screen** বেছে নিন।
3. হোম স্ক্রিনে "নিজের খাতা" আইকন আসবে। এটি পূর্ণ স্ক্রিনে খোলে, ঠিকানা-বার ছাড়া।

ইন্টারনেট ছাড়াও খাতার মূল পাতা ও টার্মিনাল খোলা যায়; ব্যক্তিগত ভল্টের ফাইল শুধু অনলাইনে লোড হয়।
