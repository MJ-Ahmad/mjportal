# কেস পোর্টাল — CYB-2026-0061 (REG-000153)

পাসওয়ার্ড-সুরক্ষিত ক্লায়েন্ট পাতা। সব লেখা `data.json` থেকে আসে।

## ফাইল
- `index.html` — ক্লায়েন্টের দেখার পাতা (বাংলা/EN টগল, পুনরুদ্ধার মিশন অগ্রগতি, রোডম্যাপ, টাইমলাইন, সহায়তা খরচ, চুক্তির খসড়া)
- `data.json` — সব তথ্য; এখানেই হালনাগাদ করবেন
- `documents/` — কাজের নথির তালিকা (আসল স্পর্শকাতর নথি এখানে প্রকাশ্যে রাখবেন না)

## হালনাগাদ করার নিয়ম
- নতুন অগ্রগতি: `ledger.entries`-এ একটি অবজেক্ট যোগ করুন, `date` লিখুন `2026-11-24T21:30:00+06:00` ফরম্যাটে (টাইমস্ট্যাম্প)।
- ধাপের অবস্থা: `tasks[].status` = `done` / `doing` / `todo`।
- ফি নির্ধারিত হলে `investment.total` বসান। পরিশোধ হলে `ledger.entries`-এ `"type":"payment","countsAsPaid":true,"amount":৫০০` যোগ করুন।

## গোপনীয়তা (গুরুত্বপূর্ণ)
- পাসওয়ার্ড শুধু পাতা আড়াল করে। `data.json`-এর সরাসরি লিংক জানলে যে কেউ পড়তে পারে, তাই এখানে এনআইডি, ফোন নম্বর, অভিযুক্তের নাম/ছবি বা টিকটক লিংক রাখবেন না।
- GitHub Pages-এ রাখলে রিপোজিটরি **Private** রাখা ভালো, অথবা পাতাটি অন্য কোনো সুরক্ষিত হোস্টিংয়ে দিন।
- পাসওয়ার্ড বদলাতে: নতুন পাসওয়ার্ডের SHA-256 হ্যাশ `security.passwordSha256`-এ বসান।

## দ্বিভাষিক লেখা
প্রতিটি লেখা `{"bn": "...", "en": "..."}` আকারে। নতুন অগ্রগতি বা ধাপ যোগ করার সময় দুই ভাষাতেই লিখুন; মিশনের শতাংশ `tasks[].status` থেকে নিজে হিসাব হয় (`done` = পূর্ণ, `doing` = অর্ধেক)।

## ব্যক্তিগত নথি (`documents/`) — প্রকাশ করবেন না
`documents/`-এ ক্লায়েন্টের স্পর্শকাতর তথ্য ও বিশ্লেষণ থাকবে। তাই `.gitignore`-এ রাখা আছে; শুধু `index.html` ও `data.json` হোস্ট করুন।
- `meeting-questionnaire.md` — আজ রাতের প্রশ্নমালা
- `case-analysis.md` — যাচাই ছক, সামঞ্জস্য-পরীক্ষা, ঝুঁকি, আইনি পথ, ৭ দিনের পরিকল্পনা
- `signing-sheet.html` — A4 এক পাতার স্বাক্ষরপত্র (ব্রাউজার থেকে প্রিন্ট করুন)
- `evidence-checklist.md` — প্রমাণের চেকলিস্ট

## হালনাগাদ টুল
`python3 tools/pr.py show | task | doc | log | fee | pay | check` — বিস্তারিত ধাপ `documents/update-playbook.md`-এ। `tools/` ও `documents/` হোস্ট করবেন না।
